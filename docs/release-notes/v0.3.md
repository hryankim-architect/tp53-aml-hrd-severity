# v0.3, tp53-aml-hrd-severity (formal model comparison + mediation + clonal hierarchy)

Third public release. **Capability portrait, not a research result.**

## What this release adds

v0.2 brought a real Telli 2016 HRD-scar axis alongside the v0.1 TP53
axis, and ran univariate / bivariate / interaction Cox models. The
output was a descriptive table, but it left the most
interesting interpretive question unanswered: **is TP53 mechanistically
upstream of HRD-scar, or are the two axes just correlated proxies?**

v0.3 wires three new substrate-bracketed analyses that decompose that
question:

### 1. Formal nested Cox model comparison (`src/tp53_hrd/model_compare.py`)

Three nested models from v0.2 are now compared *pairwise* by LRT,
AIC, and C-index:

```
M1 = severity_score                              (univariate TP53)
M2 = severity_score + hrd_score                  (bivariate)
M3 = severity_score + hrd_score + TP53 x HRD     (with interaction)
```

For each pair (M2-vs-M1, M3-vs-M2, M3-vs-M1) the pipeline emits:

- `lrt_p`, likelihood-ratio test p-value
- `aic_delta`, AIC complex − AIC simple (negative = complex preferred)
- `cindex_delta`, Harrell's C-index change
- `justifies_complex`, boolean: `(lrt_p < 0.05) AND (aic_delta < 0)`

This automates the "is the interaction term worth keeping?" decision
per run.

### 2. Causal mediation analysis (`src/tp53_hrd/mediation.py`)

Baron-Kenny (1986) mediation framework with non-parametric bootstrap
CI on the indirect effect (VanderWeele 2015):

```
Path a:  TP53_severity --(OLS)--> HRD_score        coef, p-value
Path b:  HRD_score --(Cox|TP53)--> survival         log-HR, p
Direct:  TP53_severity --(Cox|HRD)--> survival      log-HR, p
Total:   TP53_severity --(Cox)--> survival          log-HR, p
Indirect = a * b   (Baron-Kenny product)
Proportion mediated = indirect / total
95% CI on indirect via 1000-resample bootstrap
```

This tests the hypothesis that HRD-scar accumulation is mechanistically
downstream of TP53 LOF.

### 3. Clonal hierarchy approximation (`src/tp53_hrd/clonal.py`)

For each TP53-mutant patient in the cohort, rank TP53's max-VAF
against the patient's other somatic mutations from the open-tier MAF:

- `founder_consistent`, TP53 max-VAF is in the top 3 mutations
  (likely founding clonal event)
- `subclonal_consistent`, TP53 max-VAF is below the cohort median
  (likely secondary acquisition)
- `ambiguous`, neither extreme

The headline aggregate is **`founder_rate_among_tp53_mut`**, what
fraction of TP53-mutant patients carry TP53 as a likely founding
event. A high founder rate is *consistent with* (but does not
*prove*) the "TP53 upstream of HRD" causal hypothesis.

## What v0.3 deliberately does NOT claim

These analyses **strengthen** the interpretive case for the
TP53→HRD-scar upstream-downstream story, but they do not formally
**prove** causation. Cox + Baron-Kenny mediation is association
decomposition, not strict causal inference. Strict causal-mediation
claims require:

- No-unmeasured-confounders assumption (NUCA), violated by any
  cohort the size of TCGA-LAML where unmeasured chromosomal events
  are likely confounders
- Temporal ordering verification (clonal hierarchy), our VAF-rank
  proxy is *suggestive*, not definitive; proper analysis needs
  CCF/PyClone-VI or single-cell DNA-seq, both out of scope
- Mechanistic functional data, TP53 KO mouse models or cell-line
  HR-repair assays

The README climax frames the three new outputs as
*"converging-evidence triangulation"* rather than *"causal proof"*,
with each axis bounded by its own scope caveats.

## Real-data smoke (TCGA-LAML n=15, same cohort as v0.1+v0.2)

```
[Model comparison]
  M2 vs M1 (add HRD)        : lrt_p, aic_delta, cindex_delta, justifies
  M3 vs M2 (add interaction): lrt_p, aic_delta, cindex_delta, justifies
  M3 vs M1                  : lrt_p, aic_delta, cindex_delta, justifies

[Mediation]
  path a  TP53 -> HRD       : coef, p
  path b  HRD -> survival|TP53 : log-HR, p
  direct  TP53 -> survival|HRD : log-HR, p
  total   TP53 -> survival     : log-HR, p
  indirect (a * b) with bootstrap 95% CI
  proportion mediated

[Clonal hierarchy]
  n_tp53_mut, founder_consistent, subclonal_consistent, ambiguous
  founder_rate_among_tp53_mut
```

Exact numbers from the most recent `make run` are persisted in
`artifacts/survival_summary.json` under the
`model_comparison_lrt_aic_cindex`, `mediation_tp53_via_hrd`, and
`clonal_hierarchy_summary` keys.

## Audit trail

Three new audit emissions per run:

- `survival.nested_model_comparison`
- `survival.mediation.computed`
- `clonal.hierarchy.computed`

Together with the v0.2 `survival.bivariate_cox.computed` emit, every
analytical claim in the README climax is reproducible from the audit
ledger alone.

## New tests

- `tests/test_model_compare.py`, synthetic two-axis cohort exercises
  the LRT/AIC/C-index machinery; a noise-only HRD cohort verifies
  `justifies_complex` correctly returns False
- `tests/test_mediation.py`, fully-mediated synthetic cohort
  (TP53 → HRD → survival by construction) verifies proportion-mediated
  approaches 1; unmediated cohort verifies it approaches 0; bootstrap
  CI on indirect effect tested for both regimes
- `tests/test_clonal.py`, founder / subclonal / ambiguous / no-tp53
  call edge cases plus the cohort-level summary
